# J4a 两字段路线查询：实现前冻结契约

2026-11-07，`route-v1` / `route-feedback-v1` / `route-completion-v1`，`calibrated:false`。这是类型化多字段首批，非任意表单、路线规划效果或完整 J4 准入。

## 任务定义

`intent:"route_search"`，必须显式 `decision:"jev"`；`inputs:{origin:string,destination:string}`，`targets:{form,origin,destination,submit}`，`completion:{type:"visible",id}`。所有 ID 为同包完整资源 ID，互不相同；输入必须为非空字符串，每值不超过 2000 字符，拒绝 C0/C1 控制字符（含 TAB/换行），不 trim/改写实际值。不得混入 query、checked、自由参数、loading、searchActions 或其它完成条件。

单包前台、display 0、同窗口/Activity、同租约。两个字段与提交按钮须位于同一个声明 form 内。没有入口导航、滚动、IME、焦点 Tap、字段联想选择、登录/支付/凭据、任意生成输入或持久恢复。已有 System 授权契约不受本意图影响。

默认 60000ms / 3 动作 / 96 图采样 / 6 模型；maxActions 允许 1–3，观察 8–256，模型 0–16，总时间不超既有 300000ms。最多 6 轮，连续第三次可信 stale 停止；已验证 Fill 才重置连续 stale。最多每字段一次 Fill、一次提交 Tap，无动作补偿。

## 原始证据与进度

- 完整原始树对所有声明 ID 唯一，包括隐藏和折叠节点。form、字段、submit 完整可见启用；form 非交互；字段须 TextField、password 明确 false、checked/checkable 非 true、text 为明确字符串；submit 为可点击的非编辑/非 checkable 控件。
- 字段与 submit 的原始节点位于 form 内，动作图必须指向同一原始节点。拒绝隐藏/禁用/密码/交互祖先。全树 editable/TextField 只能是两个声明字段，拒绝额外输入/密码控件（包括隐藏节点）。
- 焦点最多一个，且只能是 origin/destination/submit；字段 focused 属性必须明确 true/false。Fill 使用精确 selector，不根据焦点投递文本、不为焦点额外点击；每次决策后的复采和写前摘要包含焦点。
- 初始和每轮必须两次完整稳定采样。完成标记原始身份在任何写入前及提交前必须不存在，隐藏/空标记也算预存。
- 两字段按宿主角色绑定输入引用。已稳定读回正确的字段不再填入；Jev 只能在尚未验证字段的 Fill 候选中选一个，候选顺序固定 origin/destination，或者 escalate。每个候选自带宿主固定 inputRef。
- Fill 后既有 RPC getText 必须精确读回，再以原始树稳定读回两次验证该字段及全部已验证字段；缺失/改值/错角色/不安全/上下文变化停止。已验证字段在后续观察、升级交还、下一次写前丢失时不允许重填。
- 两字段都经稳定证据验证后，才产生 submit/Tap 候选。决策后和派发前再次验证两字段精确值、唯一/受限焦点、同 form、完成标记不存在。模型不能换输入引用、改文本或任意指令。
- 提交最多一次。后置需要同窗口唯一、安全、完整可见的指定结果标记连续稳定出现两次，再做最终宿主核验；不证明路线内容、持久化或其它业务效果。内部后置和最终验证共享提交前启动的最长 5000ms 窗口及原总截止。每次 Fill 的原始树后置同样有从派发前启动的五秒上限。

## 取消、升级、隐私与职责

仅可信且明确未派发的 stale 可归还动作预算并重新决策。任何已派发未知写、读取失败、字段进度丢失、上下文变化或策略拒绝均不能通过重试/升级洗绿。

显式 main_agent 或 human 继续最多一次，沿用原预算、租约与取消排干；select 只能选当前绑定候选，reobserve 只重新观察，stop 终止。人工交还可补齐尚未验证字段，但不能修改已验证值；不能把历史完成证据当作提交成功。viewer 接管仍取消原任务。

Jev 与实际主 Agent 只接收声明 ID、origin/destination 引用、封闭角色、匹配布尔、阶段、已验证引用及原预算；原始输入、标签、描述、XML、截图和异常正文不外发。轨迹保留 inputRef 与真实回执，不保存文本。旧 search-v8/toggle-v1 协议不接受 route 字段，route 也不接受旧动作。

单独实现路线循环和原始表单证据；提取已有概率回答校验为共用模块，搜索对外导出保持。复用任务运行时、原子动作、模型/升级/轨迹生命周期，不增加新锁或服务容器。

## 验收冻结

1. 两种填入顺序、相同/不同值、保留空白及 Unicode、一个/两个预填正确字段；独立检查实际写入目标、值和提交快照。
2. 缺值/错类型/重复 ID/隐藏重复/错 form/错角色/密码/额外字段/焦点不明或越界/预存结果，零写拒绝。
3. RPC 与原始树读回不一致、填写错字段、先填值被第二次 Fill 改坏、稳定性失败、上下文变化、结果隐藏/重复/不安全，停止且不重放。
4. 模型参数伪造、旧观察答案、低置信/无效回答、未派发 stale、第三次上限、字段预算、观察预算、模型超时、总截止。
5. 主 Agent select/reobserve/stop/错误角色/改值/缺服务、人工交还/拒绝/修改已验证字段、取消后依赖排干与 unknown 保留。
6. 两仓闭词表、版本隔离、隐私、最大预算轨迹容量与终止预留；前批搜索和开关固定回答对照及限定全集回归，记录实际退出码与前后 SHA-256。
