# J3.1 同包搜索动作契约

2026-11-07 实现前冻结。基线为本批改前 search-v5；候选 search-v6，search-feedback-v2，完成策略仍 search-completion-v2，calibrated:false。只做离线替身验证，不发送真实模型探针或操作真机。

## 范围与选择

复用现有 task-port、ExecuteStep 原子执行、策略和写前 fence；不建立第二套动作执行器。普通搜索保持原精确词表和 Tap/Fill 路径。新增可选 `searchActions` 仅适用于 decision=jev，由任务调用方预声明，模型不能增加或修改：

- `imeAction: enter|search`：只在原查询已写入并独立读回后提供 IME 提交。原框未聚焦时先提供 Tap 聚焦，后置条件是全原始树唯一焦点落在同一安全输入框、输入精确匹配且上下文不变；已聚焦则直接提供 ImeAction。提交前新观察及最终写前 fence 再次证明焦点/输入，完成仍走原独立完成谓词。当前字段与其它可编辑字段/焦点歧义时停止，不猜默认输入框。
- `scroll: {command: Scroll|ScrollUntil, container: 同包ID, target: 同包ID, direction: up|down|left|right}`：仅在输入前查找预声明搜索入口或查询框；容器必须在完整原始树唯一、可见启用且明确 scrollable。目标可暂不存在，出现后必须唯一、在该容器后代中、滚动轴两端内侧可见，且符合原搜索词表。模型不能生成容器、目标或方向。
- 本批两种滚动均至多一次物理 swipe。Scroll 固定 distance=0.6/duration=300；ScrollUntil 固定 host/maxSwipes=1，禁止不透明 RPC scrollTo 内部多次滚动。后置条件必须证明指定搜索目标可用，只有页面/装饰变化不能继续。未找到目标停止，已派发但未证实仍 unknown，不重放、不降级、不假称到边界。同容器重复滚动/多屏查找留给后续独立契约，不以总预算冒充进展证据。

`searchActions` 必须非空、无未知字段，不接受 rules/shadow、跨包 ID、完成标记作为查找目标、参数 getter 或任意选择器。选择 IME 不同时提供普通提交按钮；显式滚动仅在没有可用普通候选且预声明目标未可用时出现。已填输入不会因滚动而丢失，因为本批不在输入后提供滚动。

## 决策和证据

新增阶段 seek/focus；候选仍单问绑定当前观察，动作参数固定在候选的 `parameters` 中。反馈只增加已验证 seek/focus 的历史和事件，原最近三条上限、八轮上限、动作/观察/模型预算、等待/stale/升级额度不变。scroll 的方向与目标、IME 动作进入轨迹及上游主 Agent 的封闭投影；无原始标签、文本值、类名或树路径外发。旧轨迹保留原版本形状；v6 强制新增参数、阶段、后置条件的兼容性和授权范围。

## Gate 与证据口径

实际 Service/XML → 执行器 → task-port → 策略/fence → 设备替身，使用真实 trace 和主 Agent 投影。覆盖 enter/search、无需聚焦/先聚焦、焦点歧义/转移、输入丢失、最终派发前变化、错误高置信、四方向、目标不存在/容器外/边缘/重复/敏感、装饰变化、未知写、预算耗尽、取消、升级和旧回答。证明实际派发次数、目标、命令及后置条件，不能只断言成功或停止。

固定 v5 普通场景对照应保持动作、调用次数和停止结果；新增能力用自己的场景分母，不与旧基线泛化比较。运行最终限定回归并冻结源码哈希、容量、退出码，保留失败日志。当前单包上下文规则继续拒绝权限弹窗、外包 IME 树和窗口/尺寸变化；本批不能据此宣称适配所有键盘和 App。真实 J0.2 校准及设备/App 联合准入仍未完成。
