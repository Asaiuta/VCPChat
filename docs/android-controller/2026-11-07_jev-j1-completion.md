# J 系列首批：完成契约统一

日期：2026-11-07。对应 [J0.1 / J1.1](2026-11-07_jev-loop-roadmap.md#J1)。当前状态与最终测试数字统一维护于 [README](README.md)。

本批先冻结下列契约，再通过离线回归实现；不调用上游模型或真实设备。J0.1 本批只交付完成策略身份、完成证据及对应夹具，不代表模型版本、usage、概率摘要等校准证据已经齐全。

## 冻结范围与判据

- 三种 decision 使用同一原始树完成谓词；有 item 时空结果容器可以继续，完整旧结果在写入前停止。仅 ID 契约保留对预存标记的保守拒绝。
- entry 后置验证使用同一预存判据，不能因为新页面有空容器而拒绝已确认的搜索进展。
- 提交一次后只读等待完整谓词：唯一可见容器、条目数、可选输入匹配与容器外 absent 条件均需成立。
- 完整谓词与整页摘要、可信上下文连续两采样一致，采样间隔仍为 200ms。闪现结果、目标外变化或上下文变化不能报告完成。
- 容器等待与最终完整谓词等待共用 5 秒局部窗口，从提交尝试进入设备执行前开始，包含最后派发复核和输入耗时；同时受原总截止和观察预算约束。未派发 rules stale 重试可以建立新尝试窗口；已派发提交不能重试或重置窗口。
- 完成策略标识为 `search-completion-v2`，与 Jev 候选策略 `search-v1` 分开记录。Jev 仍未校准；没有新增模型调用、模型输入字段或设备 RPC。
- 未知写、取消、策略和所有权沿用原执行链；完成验证失败不改写已存在的原子回执，不触发 Back、重新填写或重新提交。

## 离线验收

[完成契约回归](../../tests/android-task-completion.test.js) 通过真实 Service 和原始 XML 替身，分别覆盖 rules/shadow/jev 的空容器、多级阶段、延迟条目、旧结果、错误条目与容器外负向条件。断言具体写序列、模型调用、原子回执、完成样本和输入不入轨迹。

虚拟时钟用例独立验证剩余窗口、结果闪现、目标外变化、上下文变化及提交耗时超过窗口，避免以真实设备时序替身冒充模型质量证明。现有测试继续覆盖取消/截止、unknown 隔离、轨迹容量、输入/策略与所有权。

改前文件保存在 [本批证据目录](../../artifacts/android-jev-j1-2026-11-07/)。原审查复现及历史日志保持不变。
