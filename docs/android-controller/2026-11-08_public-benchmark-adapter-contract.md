# 公开基准适配契约

本批只实现探索适配与离线验证。使用固定官方 revision 的任务定义和检查器，复用正式 J0.2 的冻结、RunTask、逐写审计与报告，不产生 calibrated:true。真实环境与模型运行由后续批次提供证据。

## 冻结与范围

- AndroidWorld：首批选择中的任务使用原版参数生成器、同一个 TaskEval 实例的 initialize_task / is_successful / tear_down。参数在运行前物化，保留完整类型化参数，包括日历目标行和噪声行；运行时不能重新随机生成。
- AndroidLab：setting_7、setting_3、clock_1、map_12 使用固定源码中抽取的原版确定性 judge 及其纯函数依赖，使用原版 XML 压缩器。评分范围为最终状态，不冒充上游逐轨迹聚合成绩。生命周期采用专用模拟器的冻结快照恢复，明确属于适配探索环境。
- contacts_2 的提示要求 gmail，检查器要求 qq，阻塞为 UPSTREAM_GOAL_ORACLE_CONFLICT。map_1 需要任务答案通道及单独计费的模型裁判，阻塞为 ANSWER_AND_JUDGE_CHANNEL_REQUIRED。其余目录项仍为范围外，不能静默删除。
- 固定源码、解释器及依赖身份、不可变环境资产、参数、目标、独立起始/结束检查器、预算和各臂模型身份。编译时核对准备包、选择与源码摘要；冻结后任何漂移使批次失效。
- 每个上游任务模板固定一个 clusterId，参数变体和重复执行不增加独立样本。当前所有公开基准批次仅允许 exploration。

## 执行与证据

1. 校验冻结身份和指定模拟器，不自动安装 App、建立快照或启动模拟器。
2. 启动受限 JSONL Python 桥；每个 trial 只有一个生命周期实例，固定初始化/评分/清理命令，无任意 shell 钩子。
3. 原版初始化或快照恢复后启动目标 App；独立原始 XML 检查起始状态及结果未预先存在。此处固定为单 App 起始范围，不覆盖 AndroidWorld 原版从主屏开始的导航；属于适配探索，不是官方榜单复现。
4. 原样把冻结目标、输入、预算交给现有 RunTask。桥不运行 Agent、不访问模型账号、不调用上游评分主入口。
5. RunTask 排干后先保存独立最终 XML，再调用上游检查器。官方评分、独立检查、Agent 完成声明分别保留；未知评分不视为成功，官方得分不能抵销独立检查失败。
6. 尝试原版 tear_down / 环境关闭或快照恢复，并确认桥进程退出。初始化部分失败也需要清理；超时、协议损坏、清理不明一律停止，不重放写入。

初始化、评分、清理分别设总超时并纳入 worker 截止。检查器异常记 unknown 和原因，不能当作任务失败样本删除；未知传输继续触发原有停批规则。独立审计仍逐写进行，拒绝率不能单独优化。

## 离线退出条件

验证参数类型往返、生命周期实例保持、检查器真假及异常、完成冲突、初始化失败后的清理、超时/异常退出、源码漂移、不可重放、三臂冻结与报告 schema。覆盖支持范围内的原版确定性评分器；环境缺失必须保留在 readiness 清单，模拟依赖测试不能称为原生环境运行成功。

Evidence → Finding → Path：固定源码揭示生命周期对象状态、AndroidLab 评分入口探针、contacts_2 提示/检查器矛盾；因此使用持久桥、隔离确定性评分、显式阻塞清单；后续由匹配的专用模拟器、真实绑定和真实工作负载完成运行验证。
