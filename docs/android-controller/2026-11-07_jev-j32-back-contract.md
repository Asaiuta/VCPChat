# J3.2a 同窗口返回搜索冻结契约

2026-11-07，实现前冻结。基线 search-v7；候选 search-v8 / search-feedback-v4。完成策略和搜索词表不变，calibrated:false。仅离线替身，不访问真实模型或设备。

## 范围与结构

`decision=jev` 可声明 `searchActions.back:{from,target}`：from 是当前非编辑面板的同包完整资源 ID 标记，target 是返回后必须可用的搜索入口或输入框 ID。两者不同，也不得使用完成标记、条目或加载标记。宿主固定 KeyEvent back，模型不能指定键或改变目标；每任务最多一次已派发 Back。它是预声明导航，不是失败补偿或未知写恢复。

仅支持同包、同窗口/Activity 的页面或面板切换，沿用全部上下文、策略、租约和原子执行链。跨 Activity/包、LaunchApp、LongPress 本批不接入；这些需要自己的前后身份与效果契约。新增逻辑放入局部返回证据模块，现有循环只负责编排，不新建执行框架。

## 前后条件

- from 原始身份唯一、明确启用、完整可见，节点及祖先不得隐藏、禁用、密码、可编辑或可点击。整棵原始树不得含输入框、editable、password 或 checkable 节点，包括隐藏节点；宿主不能从“输入为空”推断没有草稿。该约束仍不证明应用不存在隐藏业务状态，调用方声明必须对应已知非编辑面板。
- target 在返回前原始树中必须不存在。from 存在时只提供 Back 候选；不点击面板背后的普通搜索控件。已 Fill、已进入滚动查找或已有 Back 验证后，from 再出现硬停止。未声明或 from 不存在不凭空生成 Back。
- 新观察和最终写前 fence 再验证来源；可信未派发 stale 可在原预算内重新决策。已经派发后不重试；错误高置信、无变化、装饰变化、目标错误/重复/隐藏/密码/不符合搜索词表、来源未消失均不能证明成功。
- 返回后 from 必须从原始树消失，target 必须唯一、启用、完整可见且符合原搜索词表；两次连续独立采样完整摘要/上下文稳定，才确认导航进展。模型 ACK 不证明效果。
- 确认返回后，下次输入或入口动作仍绑定该 target；目标丢失即停止，入口进入新表单或 Fill 验证后才解除此临时绑定。已用 Back、循环记录、原预算不因等待、stale、主 Agent 或人工交还重置。

## 协议与验收

新增阶段 back、固定参数 `{key:back,revealId:target}`、后置条件 `search_back_progress`、反馈事件 verified_back。候选的 targetId 是来源标记证据，不表示按键有元素级派发目标。轨迹及主 Agent 投影按 search-v8 校验声明与参数；旧策略不能容纳新增 Back。原始文字、类名、输入内容不外发。

验收使用生产 Service/XML/fence/原子回执/轨迹/上游投影及离线设备、模型和交互替身。覆盖成功返回输入框/入口、IME组合、未声明/已有目标、来源安全、隐藏编辑或密码/选项、错误目标、稳定性、模型等待与最终派发 stale、次数与原预算、unknown、取消排干、主 Agent/人工交还和协议篡改。断言实际按键次数、后续动作、模型调用和回执，不只断言终态。保持旧普通搜索及单次动作固定回答对照，保存首轮失败、最终限定回归与源码摘要。

## 实现期审查补充（同日）
