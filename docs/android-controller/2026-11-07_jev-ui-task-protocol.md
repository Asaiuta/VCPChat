# 通用 UI 任务循环与真实探索冻结协议

2026-11-07，`ui-task-protocol-v19`，策略 `ui-task-v19` / `ui-elements-v10` / `ui-predicates-v1`，`calibrated:false`。

用户明确选择“做类似 jev-android 的通用任务循环，支持自主导航、多步骤操作和目标判断”。本协议新增 `RunTask intent=ui_task`，与历史 search-v8/v9、toggle-v1、route-v1 分开。当前改动不将任何历史批次改成成功，不继承校准结论。

参考已实际读取的 `dougsong/jev-android` 提交 `be8364ad1a7596172f8cd79c70d2462f4dd0f4dc` 的 Models、JevAgent、JevProvider：从当前控件能力构造有限动作表；输入值由调用方提供；接受派发与页面变化不等于业务成功；DONE 只是模型声明。实现不依赖参考仓库运行，也未复制 Kotlin 源码。原路线图引用的 `droidrun/mobile-jev` 是另一份参考。

## 契约

调用方提供 `goal`、`package`、可选 `allowedPackages`、具名 `inputs`、操作白名单 `operations`、总预算和可选完成检查器。Jev 接收目标、具名输入值、有上限的界面标签、角色、checked/selected/focused、输入匹配引用、近期动作与效果；这与旧搜索封闭词表的外发边界不同。密码及密码子树不提供给模型。原始目标、输入、屏幕标签不进入通用轨迹，只记录输入引用、摘要和观察关联。

v5 增加最多四层可见非密码祖先的资源ID/角色/非输入标签，目标描述携带最近容器上下文，区分同名内容在不同页面/列表中的来源。

v6 补齐参考实现中的输入框当前值：非密码字段向模型提供最多160字符的 value 和显式 valueTruncated；inputMatches 仍按完整原文精确比较，截断展示不参与完成验证。字段值仅进入本次模型请求，不进入轨迹。候选概率、预算与完成条件不变。

v7 将重复祖先归并为共享 contexts 与逐节点 contextRefs，完成条件和逐项结果放入同一 requirements 数组。操作问题的 Fill 描述包含当前可用字段和绑定输入，目标问题继续独立通过门槛；删去每个问题中重复的完成条件 JSON。所有可派发候选、概率、预算和完成检查不变。

v8 把完成条件内显式 text.id/inputRef 绑定作为填写约束。已可见、唯一且可写的绑定字段尚未满足时，只提供这些字段对应的 Fill 候选以及等待/停止；条件字段尚未出现或不能直接 Fill 时保留通用导航。显式绑定字段不接收其它具名输入。该规则适用于声明精确输入的通用表单，不含 App ID 或搜索专用词表；概率门槛及完成谓词不变。

v9 所有操作问题携带其实际候选描述，使操作与目标问题获得相同的可用控件信息；明确同表单的可见提交按钮优先于等效键盘操作。动作后页面变化须连续两次观察稳定才提前结束原五秒等待窗口，降低把导航动画当成下一步页面的风险。两头门槛、写动作预算和最终完成条件不变。

v10 允许在原五秒动作后/完成等待内重新获取明确以 UI_CONTEXT_CHANGED 拒绝的只读采样，计入观察预算及连续 stale 上限，轨迹单独记录 sampling_context_changed。丢弃不一致树，下一次完整采样仍须包白名单、display0、未锁与上下文证明；未知写和传输错误仍硬停，不重派动作或延长窗口。工作区发生并行改动时可从按 sourceIdentity 清单复制并复核的隔离源码运行；依赖及本机设置通过目录联接读取，协议继续记录实际执行字节及设置摘要。

v11 向决策暴露 pageSettled；五秒效果观察结束时页面仍持续变化则不给写候选或Done，只允许原模型预算内的wait/escalate。再次等待仍为五秒且共用原120秒截止、96观察和8模型调用，不用连续过期的写决策来等待加载，也不因行出现而放宽整页稳定完成谓词。

v12 在构造问题前按剩余写预算移除不可执行的写候选，保留合法Done以及wait/escalate；避免预算已耗尽仍让模型选择滚动并消耗stale恢复。派发前发现观察变化会将pageSettled置false，先等待稳定再提供写候选。原硬预算检查继续保留，所有数值门槛不变。

v13 支持可选 loading:{id}：调用方声明表示后台工作进行中的同包标记，模型收到 declared/active 布尔证据。唯一安全可见时不给写候选；原五秒等待不会仅因中间结果短暂稳定就提前结束，标记消失或完成条件满足且稳定时可提前结束。标记仅授权有界只读等待，不是完成证据，预算不刷新。本次真实App已观察到搜索期间fb_stop（停止搜索）存在，故冻结loading.id=io.legado.app.release:id/fb_stop；不改变书名/作者同一行检查器。带检查器的Done仅请求新鲜只读验证，因此同上下文内容变化直接交给原五秒/两次稳定完成谓词判断；任一条件丢失仍失败，不因旧模型声明通过。

v14 将采样前CONTEXT_UNPROVEN纳入与采样后UI_CONTEXT_CHANGED相同的只读窗口重采。二者均不允许使用被拒绝的树，不改变写前上下文检查，不跨越原窗口/连续三次上限；下一次完整采样仍必须证明前台、包、显示器和解锁状态。

v15 增加完整采样准入余量：等待窗口剩余不足1500ms时不再启动前探针→RPC树→后探针链。五秒上限不延长，不吞掉UI_SERVER_TIMEOUT或未排干传输错误；只避免用尾部几毫秒启动明知难以完成的采样。完成仍须在原窗口内取得两次完整稳定满足的样本。

v16 将显式加载与页面未稳定的等待交给宿主算法：每段最多五秒，只计入原观察预算和总截止，不消耗模型调用或决策轮次。两次完整观察稳定，且加载标记消失或原完成谓词已满足，才进入下一次 Jev 决策；目标出现后仍保留原 Done 和稳定完成核验。单段结束未就绪则继续下一段，剩余不足完整采样余量时停止；不刷新总截止。轨迹 wait.source 区分 host/model，reason 为 loading/page_unsettled/model_requested。原 8 模型、3 动作、96 观察、120 秒及概率门槛均不变。

v17 同步决策提示与 v16 宿主就绪条件：目标已可见且全部声明要求满足时，后台其它内容继续加载不单独构成 wait 理由；Done 仍只申请新鲜稳定核验，未满足目标仍不能完成。保留 wait/escalate 选择及原0.90/0.20门槛。就绪窗口未能取得任何完整新样本时停止，避免空轮询产生无观察支撑的等待事件。

v18 / ui-elements-v10 保留匿名或同名祖先容器的逐观察身份：以原始节点对象生成局部引用，共享 contexts 只归并同一个原始容器，不按标签/资源ID合并不同结果行。前四层祖先包括无ID无标签容器；同一行的书名/作者获得相同父引用，不同行获得不同父引用。对外不暴露原始结构路径，轨迹仍只存摘要。完成谓词及概率门槛不变。

操作包括 Tap、Fill、Scroll（四方向）、Back、ImeAction、LongPress、LaunchApp。每个候选绑定当前观察内的节点引用与完整参数引用；资源 ID 仅为模型提示。宿主在内存中将引用映射到新鲜快照索引，支持无 ID 与重复 ID 控件。Fill 仍须满足设备 RPC 唯一性与精确读回；不可证明的字段不会获得 Fill 能力。包白名单、display 0、未锁定、完整观察、设备租约、交互策略、派发前复采和未知写停止规则继续执行。

v4 把原目标和尚未满足的完成条件写入每个问题的 instructions（与参考实现一样，不只放在 state 中），同一次请求内各问题独立得到目标约束。v3 起采用同一次请求中的操作问题与各操作的条件目标问题。只消费被选分支，操作和目标各自必须通过原概率门槛 0.90 和领先差 0.20，不做概率乘积；每条目标仍是动作/参数已绑定的联合候选，零网络重试；每次等待最多五秒，任务总截止不刷新。最多连续三次“已证明未派发 stale”可重观察。已接受动作只记录 dispatched/verified 原始回执，再观察页面变化；变化不是成功证明。相同页面上的同一动作组合不重发，包括重新回到已访问页面。

v2 将调用方声明的完成条件与逐条件布尔读回发送给模型；已知条件未满足时不提供 Done 候选。模型选择 Done 后，有检查器则必须在五秒内取得间隔至少 200ms 的两次完整稳定、谓词满足的观察，才返回 completed。无检查器返回 unverified，禁止包装成 verified。检查器支持 all 内的 visible、absent、checked、精确 text、同一直接结果行 row 的多个精确字段；不执行调用方代码。不同结果行不能拼接。

## v19 离线协助契约

v19 显式接受 assistance=none/main_agent/human，默认none。仅有效 TASK_JEV_UNCERTAIN 或显式 escalate 可进入一次协助；非法响应、未知写、上下文不明和传输失败仍停止。所有任务族共用同一协助调用器：主Agent最长10秒、Handoff最长60秒，都受原总截止/取消约束，等待真实依赖排干后才释放租约。主Agent沿用发起请求实际模型，只能select当前候选、reobserve或stop；不得生成动作、输入、修改目标/预算/完成条件。

通用主Agent接收有界目标、非密码候选描述（含界面中当前字段值）、输入引用、条件满足布尔及原剩余预算；不发送整个inputs映射、原始树、serial或完整聊天。与旧三种类型化任务的外发范围分开，持久轨迹仍仅摘要/引用。上游独立投影校验策略、身份、候选形状、包/输入白名单、预算、无unknown回执和payload上限，回复再次绑定本次taskId/observationId。

交还复采并校验原窗口上下文；页面变化使旧选择失效。原来可见且已匹配的字段必须仍可唯一证明原值，无法重新证明则TASK_PROGRESS_LOST；当前UI或RPC不能证明身份时保守停止。人工继续不构成写授权或业务完成。升级计数和实际HTTP计数分开，缺元数据的请求数/usage维持未知；正常路径零升级调用。轨迹新增started/settled与停止证据，ordinary-event满时仍保留终止记录。

按用户指示，v19仅离线实现和验证，不进行真机或真实模型请求。v18/r21成功对应旧冻结字节，不能作为v19准入。
